# Siguiente paso único

Cerrar medición telefónica y sanear el monitor:

1. Con autorización, desplegar la rama del fix telefónico. Hacer un clic real anotando hora exacta.
2. Verificar en herramientas de red/Tag Assistant que sale el request; luego verificar en Ads tras el tiempo de procesamiento indicado por la interfaz.
3. Preparar una revisión segura del monitor: B8 debe usar estado real o eliminarse; saldo debe quedar `null/revisar Facturación` mientras Ads Scripts no exponga los fondos disponibles de forma confiable.
4. Eliminar la pausa automática A1 o convertirla en recomendación antes de la siguiente ventana de las 08:00; requiere autorización porque cambia el comportamiento de un servicio externo que puede modificar keywords.
5. Solo entonces pedir una autorización agrupada para dejar teléfono secundaria y aplicar cualquier cambio recomendado.

Procedimiento detallado: `docs/PHONE_CONVERSION_RUNBOOK.md`.
